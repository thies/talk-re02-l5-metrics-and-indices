Our route through Capital IQ

  1. Screen the US universe for industrial and infrastructure REITs.
  2. Save the selected companies as a reusable list.
  3. Request each company’s Total Market Return series and export it.
  4. Rebase the cumulative return series to an index that starts at 100.

1 · Define the universe

  • Open Capital IQ company screening and select listed companies.
  • Set geography to the United States.
  • Filter the REIT property / industry classification to industrial and infrastructure.
  • Review the constituents: remove duplicates, operating entities and inactive securities if the research question requires it.
  • Save the results as a named list, with the screen date and criteria recorded.

Capital IQ labels and screen controls can vary by account and interface version; use the equivalent fields shown in the live recording.

2 · Retrieve Total Market Return

  • Use the saved list as the company universe.
  • Select the historical Total Market Return data item for each company.
  • Set a common date range and frequency; export dates, company identifier and return observations.
  • Check the units (percentage points or decimals) and the series’ zero-return base date.

Choose total return so distributions are reflected; price-only returns omit dividends.

Record the Capital IQ field label, date range, frequency, currency and extraction date with the export.

What does a REIT return represent?

  • Total market return is the return to listed company shareholders, including price movement and distributions under the provider’s convention.
  • It reflects property performance plus leverage, corporate costs and stock-market pricing.
  • It is not the same as an unleveraged index of directly owned commercial property.

This distinction is also emphasised in the earlier “roll your own REIT index” teaching material.

3 · Rebase a cumulative return series

If Capital IQ’s cumulative total return series starts at 0%:

A base of 0% cumulative return is the same starting point as an index level of 100.

Check the export before indexing

  • Confirm that the field is Total Market Return and includes distributions.
  • Keep the date range and frequency consistent across the saved list.
  • Record the return units and extraction date with the exported data.
  • Check how the provider times and reinvests distributions.

Take-away

Saved company list → Total Market Return →
cumulative return based at 0 → index based at 100

Add 100 to the cumulative return, expressed in percentage points.

A listed REIT index measures shareholder returns, not direct-property returns.
